Apache HugeGraph

面向实时图查询、大规模图分析和 AI 原生应用的全栈图数据库生态系统，基于 Apache License 2.0 开源。

开始使用GitHub 点星
quick-start.sh
# 1. Start HugeGraph Server with Docker$ docker run -d --name=hugegraph -p 8080:8080 hugegraph/hugegraph # 2. Check the server is up via the REST API$ curl -s http://localhost:8080/apis/version # 3. Explore visually with HugeGraph Hubble$ docker run -d --name=hubble -p 8088:8088 hugegraph/hubble

为什么选择 HugeGraph

为生产级图业务打造

REST 与 RPC 接口

完整的 HTTP API，以及 Java、Python、Go、Node.js 的高性能客户端。

多种查询语言

在同一张图上使用 Apache TinkerPop Gremlin 与 Cypher，内置丰富的遍历与路径算法。

可插拔存储

支持 RocksDB、HBase、Cassandra、MySQL，以及带 PD 调度的分布式 HugeGraph Store。

可视化探索

HugeGraph Hubble 提供 Schema 管理、数据导入与浏览器内的交互式图分析。

大规模分析

面向十亿级边的分布式 OLAP 算法：PageRank、社区发现、最短路径等。

弹性伸缩

从单机嵌入式到分布式集群，支持在线 Schema 变更与备份。

快速开始

几分钟内启动一张运行中的图

使用 Docker 启动 HugeGraph Server，再用内置 Gremlin 控制台或 Hubble 界面进行探索。文档覆盖每种存储后端与部署模式。

阅读快速开始
bash
# 1. Start HugeGraph Server with Docker$ docker run -d --name=hugegraph -p 8080:8080 hugegraph/hugegraph # 2. Check the server is up via the REST API$ curl -s http://localhost:8080/apis/version # 3. Explore visually with HugeGraph Hubble$ docker run -d --name=hubble -p 8088:8088 hugegraph/hubble
