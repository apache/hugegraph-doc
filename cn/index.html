核心特点

高效

支持海量数据批量导入、毫秒级图检索，以及数千用户并发的在线操作

智能化

支持 GraphRAG、自动化知识图谱构建，并内置 20 多种图机器学习算法

易用

支持 Gremlin、Cypher 与 RESTful API，配备覆盖导入、可视化和运维的完整工具链

通用

基于 Apache TinkerPop 的属性图建模，覆盖 OLTP 与 OLAP，可集成 Hadoop 和 Spark

可扩展

支持水平扩容和分布式部署，覆盖从单机到 PB 级集群的使用场景

开放生态

遵循 TinkerPop 标准，提供多语言客户端，由活跃且持续演进的 Apache 社区支持

快速开始

Docker 默认以单机模式启动 HugeGraph Server，监听本机 8080 端口。单机模式支持内存或磁盘存储

docker run -d -p 127.0.0.1:8080:8080 hugegraph/hugegraph

其他安装方式 验证服务并执行第一次查询
