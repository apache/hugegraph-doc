Apache HugeGraph

A full-stack graph database ecosystem for real-time graph queries, large-scale graph analytics, and AI-native applications — open source under the Apache License 2.0.

Why HugeGraph

Built for production graph workloads

REST & RPC APIs

A complete HTTP API surface plus high-performance clients for Java, Python, Go, and Node.js.

Multiple query languages

Apache TinkerPop Gremlin and Cypher over the same graph, with rich traversal and path algorithms.

Pluggable storage

Run on RocksDB, HBase, Cassandra, MySQL, or the distributed HugeGraph Store with PD scheduling.

Visual exploration

HugeGraph Hubble provides schema management, data import, and interactive graph analysis in the browser.

Large-scale analytics

Distributed OLAP algorithms — PageRank, community detection, shortest path — over billion-edge graphs.

Scales with you

From a single embedded instance to a distributed cluster, with online schema changes and backups.

Quick start

From zero to a running graph in minutes

Spin up HugeGraph Server with Docker, then explore it with the built-in Gremlin console or Hubble UI. The documentation walks through every backend and deployment mode.

Read the quick start
bash
# 1. Start HugeGraph Server with Docker$ docker run -d --name=hugegraph -p 8080:8080 hugegraph/hugegraph # 2. Check the server is up via the REST API$ curl -s http://localhost:8080/apis/version # 3. Explore visually with HugeGraph Hubble$ docker run -d --name=hubble -p 8088:8088 hugegraph/hubble
