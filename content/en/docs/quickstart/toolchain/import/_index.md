Choose an import tool when you need to write file, database, or message data into HugeGraph. Use Loader for a direct import, SeaTunnel when an existing Source, Transform, and Sink pipeline should be reused, or Spark Connector from a Spark job.

- [Import data with Loader](/docs/quickstart/toolchain/import/hugegraph-loader/)
- [Import data with SeaTunnel](/docs/quickstart/toolchain/hugegraph-seatunnel-connector/#3-import-from-a-relational-database-sql2graph)
- [Read and write graph data with Spark Connector](/docs/quickstart/toolchain/import/hugegraph-spark-connector/)
