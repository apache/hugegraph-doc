本目录包含 HugeGraph Server 单机快速上手，以及分布式部署所需的 PD 和 Store 入门文档。

[DeepWiki 项目概览](https://deepwiki.com/apache/hugegraph)；涉及安装、配置和运行行为时，请以对应版本的 HugeGraph 文档及代码为准。

首次使用可从 [Server 单机快速上手](/cn/docs/quickstart/hugegraph/hugegraph-server/) 开始。该页将 ASF 已发布的 1.7.0 下载包与 `master` 源码构建分开说明。若使用 HStore 分布式存储，还需配置 [PD](/cn/docs/quickstart/hugegraph/hugegraph-pd/) 和 [Store](/cn/docs/quickstart/hugegraph/hugegraph-hstore/)。
