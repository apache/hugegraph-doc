HugeGraph provides multiple tiers of access, including multi-language client SDKs, standardized RESTful APIs, and an interactive command-line console.
The current Server REST API identifies graph resources with both a graph space and a graph name. Refer to each API page and the Server OpenAPI page for exact paths.

## Section Guide

- [Client SDKs](/docs/clients/client/)

  Official client SDKs for Java, Python, and Go to manage schemas, read and write graph data, run Gremlin traversals, and call advanced graph algorithms.
- [RESTful API](/docs/clients/restful-api/)

  Comprehensive HTTP REST API specifications covering GraphSpace management, schema DDL, vertex and edge CRUD, background tasks, metrics, and more.
- [Gremlin Console](/docs/clients/gremlin-console/)

  Interactive TinkerPop shell for offline graph manipulation, connecting to Server over WebSocket, and debugging traversals.
