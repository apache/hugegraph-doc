# About Apache HugeGraph

## One ecosystem for graph data and graph intelligence

HugeGraph is an Apache top-level project that covers transactional graph storage, distributed analytics, visualization, data loading, and graph AI.

[Read the documentation](/docs/)

[Join the community](/community/)

## The project family

- **Server** — Real-time OLTP graph queries with pluggable storage.

- **Computer and Vermeer** — Distributed and in-memory OLAP graph processing.

- **Toolchain** — Clients

- **HugeGraph-AI** — GraphRAG

## Built in the open at Apache

Follow development, report issues, and contribute through the Apache HugeGraph community.
