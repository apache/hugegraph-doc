# HugeGraph RESTful API

LLMS 索引： [llms.txt](/versions/1.5/cn/llms.txt)

---

HugeGraph-Server通过HugeGraph-API基于HTTP协议为Client提供操作图的接口，主要包括元数据和
图数据的增删改查，遍历算法，变量，图操作及其他操作。

除了下方的文档，你还可以通过 `localhost:8080/swagger-ui/index.html` 访问 `swagger-ui` 以查看 `RESTful API`。[示例可以参考此处](/versions/1.5/cn/docs/quickstart/hugegraph/hugegraph-server#swaggerui-example)
