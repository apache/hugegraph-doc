Apache HugeGraph

连接图数据与图智能的一体化生态

HugeGraph 是 Apache 顶级项目，覆盖事务型图存储、分布式分析、可视化、数据导入和图智能。

阅读文档 加入社区

项目组件

Server

支持多种存储后端的实时 OLTP 图查询。

Computer 与 Vermeer

分布式与内存型 OLAP 图计算。

Toolchain

客户端、Loader、Hubble 与运维工具。

HugeGraph-AI

GraphRAG、知识图谱与图学习。

在 Apache 社区中开放协作通过 Apache HugeGraph 社区关注开发、报告问题并参与贡献。
